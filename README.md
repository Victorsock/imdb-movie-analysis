# 🎬 IMDb Movie Analysis

Projeto de análise de dados de filmes utilizando JavaScript, HTML e CSS, com base em um dataset do IMDb (Kaggle).  
O objetivo é explorar informações reais do cinema através de visualizações interativas e organização por categorias.

---

## 🌍 Demo Online

🔗 https://victorsock.github.io/imdb-movie-analysis/

---

## 📊 Sobre o Projeto

Este projeto realiza uma análise de dados de filmes do IMDb com foco em:

- 🎯 Ranking dos 10 filmes mais bem avaliados
- 🕰️ Evolução da produção cinematográfica por década
- 👥 Filmes mais populares por número de votos
- 🎬 Visualização interativa com modais e cards
- 📈 Gráfico de evolução usando Chart.js

## 📌 Funcionalidades

### 🏆 Top 10 Filmes
Ranking dos filmes mais bem avaliados do IMDb, com modais contendo detalhes e sinopse.

### 🕰️ Filmes por Década
Visualização da evolução do cinema ao longo do tempo com gráfico interativo.

### 👥 Filmes Populares
Ranking baseado no número de votos dos usuários do IMDb.

## 📂 Fonte dos Dados

Os dados utilizados neste projeto foram obtidos a partir de um dataset público do IMDb disponibilizado na plataforma Kaggle.

Fonte: [https://www.kaggle.com/](https://www.kaggle.com/datasets/harshitshankhdhar/imdb-dataset-of-top-1000-movies-and-tv-shows)
